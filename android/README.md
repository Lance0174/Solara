# Solara Android

基于 [akudamatata/Solara](https://github.com/akudamatata/Solara) 的原生 Android 客户端。独立新增 Android 工程，未修改上游网页、后端、版权声明或业务注释。

## 使用

Android 10（API 29）及以上。安装 APK 后可直接搜索音乐，不要求先部署网站。

- **播放**：原生封面/歌词切换、歌词定位、进度拖动、上一首/下一首、列表循环/单曲循环/随机、音质选择。后台播放、音频焦点、耳机断开暂停及系统媒体通知由 Media3 管理。
- **搜索**：沿用上游网易云、酷我、JOOX、哔哩哔哩四个音源，分页搜索，加入队列及收藏。
- **音乐库**：播放队列、收藏、本地歌单统一管理。可新建多份命名歌单、重命名、增删和调整歌曲顺序，从搜索、收藏、队列及下载记录加入歌曲；也可将整个队列或收藏保存为歌单。点选收藏或歌单中的歌曲后，下一首按该列表继续播放。通过系统文件选择器导入/导出与网页版兼容的 `{meta, items}` JSON 文件。
- **下载**：选择 128K、192K、320K 或 FLAC，应用内显示进度、取消及重试。文件直接保存在公共 `Music/Solara` 目录，完成后可离线播放或加入本地歌单。新版下载按添加时间排序，文件丢失时可重新下载。Android 10+ 无需申请整个存储空间的读写权限。
- **自建站（可选）**：设置 HTTPS Solara 站点地址及登录口令，登录后手动合并同步播放列表和收藏。默认使用原仓库配置的 GD 音乐接口，也可以设置兼容接口。

下载不会打开浏览器或跳转网页。后台 HTTP 重定向由网络库完成；实际音频按文件头识别格式，网页/JSON 错误页不会伪装成下载成功。文件名和扩展名来自歌曲信息及真实音频类型，第三方接口可能返回低于所选档位的音质，下载完成后显示接口返回的码率。下载失败或取消时回收未完成文件；系统重启任务时重新获取签名音频地址，不依赖过期直链。

播放时可允许系统通知，以便使用后台通知控件。已下载音乐不依赖网络，歌词与封面仍需联网。公共音乐接口的曲库、音质与可用性由其提供方决定，应用会呈现失败与重试入口。

### 本地歌单（1.1.0）

在“音乐库 → 本地歌单”点击 `+` 创建歌单，在歌曲菜单选择“加入本地歌单”。音乐库右上角可以把当前队列或收藏整体保存到歌单；下载列表的歌单图标会保留该音频的本地地址。歌单详情支持从任意歌曲开始播放、上移/下移、移除、重命名、删除和 JSON 导入导出。重复加入不会增加相同歌曲。

歌单名称和内容保存在本机，不要求登录。删除歌单只移除该收藏集合，保留当前播放队列、收藏和已下载文件。应用内已下载地址可随本地歌单和收藏恢复；导出的便携 JSON 只包含在线曲目信息，不携带本机私有文件地址。在歌单中加入尚未下载的歌曲仍需联网播放，歌单操作不会自动触发下载。

本轮歌单交互参考 [AlgerMusicPlayer](https://github.com/algerkong/AlgerMusicPlayer) 的创建入口、添加歌单选择器和列表播放方式，继续使用 Kotlin/Compose 原生实现。升级包保持应用 ID 和签名一致，可覆盖安装保留既有队列、收藏与设置。

自建站会话用 Android Keystore AES-GCM 加密，口令不保存到普通配置或日志，应用禁止系统云备份。退出登录会清除本机会话。歌单同步为手动合并，保留两端已有歌曲；同步期间建议避免网页同时编辑歌单，原存储接口没有版本冲突协议。当前不自动同步两端播放进度。

### 网易云歌单导入（1.2.0）

进入“音乐库 → 本地歌单 → 导入网易云歌单”，粘贴公开歌单的数字 ID、网页/手机版完整链接或带链接的分享文字。`163cn.tv` 短链在应用后台解析 HTTP 跳转；若短链要求打开网页或登录，请改用完整歌单链接或 ID。整个导入过程使用原生界面，不打开浏览器。

读取后显示原歌单名称与歌曲数量，可以编辑本地名称后新建歌单，也可选择合并到已有歌单。保留歌曲顺序，自动去重，已有下载地址仍保留。读取和确认保存分开，取消会终止请求，失败不会创建空歌单。若接口只返回部分曲目，会在确认前显示原数量和实际读取数量；只有明确确认后才导入可读取部分。私人、失效或暂不可访问的歌单无法导入。

导入保存的是本地曲目列表，不自动下载音频，也不自动跟随网易云歌单更新。播放、歌词和下载继续使用现有音乐接口，导入成功不代表每首歌曲都能在线播放或下载。JSON 文件导入导出继续保留。

### 大歌单补齐（1.3.0）

网易云歌单接口可能只返回前 1000 首详情。客户端现在保留完整歌曲 ID，按每批 200 首从网易云公开详情接口补齐缺失曲目，恢复原歌单顺序并去重；已完整返回的小歌单不会增加详情请求。读取期间显示已取得数量和总数，取消会中止当前请求和后续批次，所有读取完成后才进入保存确认。

升级后，之前只导入了 1000 首的歌单可再次导入并选择“合并到”原本地歌单，补入剩余曲目且保留已有歌曲、顺序和下载地址。希望完全按网易云原始顺序重新建立列表时，可选择新建歌单。每份本地歌单仍最多 10000 首。

补齐过程不使用网易云登录或 Solara 会话 Cookie。若网络或服务出错会显示实际进度及重试入口，不自动保存半成品；若详情接口正常响应但部分歌曲已无法读取，则明确提示实际数量，由用户决定是否导入可读取部分。

### 歌单搜索与导航（1.4.0）

播放队列、收藏和本地歌单详情支持按歌名、歌手或专辑即时搜索，忽略英文大小写，多个关键词用空格分开。搜索显示匹配数与原列表总数，清空后恢复全部歌曲；搜索范围覆盖整份歌单，包含第 1000 首之后的曲目。点击结果仍按完整歌单继续播放，“全部播放”、导出及其他歌单管理操作仍作用于整份歌单。

首页左上角为探索雷达，右上角为全局搜索。播放器原下方“搜索、探索雷达、下载”收入曲目信息旁的三点菜单，原有播放控制保留。底部导航调整为“播放、音乐库、下载、设置”；设置为独立原生页面，保存后留在当前页，关于信息自动读取应用版本。

从全局搜索返回会恢复来源页面及歌单筛选、滚动位置；切换底部页面保留非敏感表单草稿。播放器的“查看播放列表”仍直接打开播放队列。站点登录口令只在当前设置页内存中暂存，提交成功或离开页面后清空，不进入页面状态保存。

### 播放缓存（1.5.0）

在线播放时自动把已读取的音频写入应用私有缓存。播放先读取缓存，缺少的内容才请求后端和音频服务器；因此已完整缓存、未过期且未被清理的歌曲，在后端返回 502 或手机断网时仍可播放，重启应用后也可使用。缓存按音源、歌曲 ID 和音质区分，不受签名 URL 或歌名变化影响。仅缓存了一部分的歌曲，未缓存部分仍需联网；更换音质时会使用该音质自己的缓存。

在底部“设置 → 播放缓存”查看用量、选择 1–5 GB 上限或手动清理，默认和最大均为 5 GB（5,000,000,000 字节）。调整立即生效，不要求登录或联网；达到容量时自动回收较久未使用的缓存。缓存从首次写入起保留 7 天，重复播放不延长期限。读取、释放与设置管理时检查过期/容量，后台每 6 小时安排一次自动检查；后台执行时间受 Android 调度及省电策略影响，过期内容不会在下一次打开时直接使用。

手动清理会保留当前仍在读取的部分，待加载器释放后清除。播放缓存与公共 `Music/Solara` 下载目录独立，缓存清理不会删除已下载音乐、歌单、收藏或站点会话。长期离线保留的歌曲仍可使用原“下载”功能。

### 播放器菜单（1.5.1）

播放器三点菜单提供“复制歌曲详情、探索雷达、下载”。搜索统一从右上角进入。复制详情会将当前歌曲的歌名、歌手、专辑、音源与歌曲 ID 作为纯文本放入系统剪贴板，无需联网；没有当前歌曲时不可复制。Android 13 及以上使用系统复制确认，较早版本显示“歌曲详情已复制”。

### 定时关闭音乐（1.6.0）

在播放器三点菜单选择“定时关闭音乐”，可直接设置 10、20、30、45、60、90 分钟，或自定义 1–1440 分钟。设置成功后立即开始倒计时，菜单及弹窗显示剩余时间，可随时取消。切歌或手动暂停不会重置计时；重新选择时长会重新计时。到期暂停音乐并保存播放位置，保留队列和应用界面。

计时由播放服务执行，离开播放器页面后继续生效，无需联网或新增权限。使用单调时钟计算时间，修改系统日期不会改变时长；后台播放沿用 Media3 的播放唤醒锁。播放服务销毁或应用进程结束时取消定时，不在下次启动时继续旧定时。不同手机的锁屏及省电策略仍需真机验证。

### 播放页固定布局与本地歌单（1.7.0）

播放页改为固定布局：封面与歌词占满剩余高度，控制区固定在底部，不再因报错提示等内容的增减而整体滑动。播放器顶部新增“加入本地歌单”快捷按钮，三点菜单也提供同名入口，可直接把当前歌曲存入本地歌单。首次进入音乐库时会默认创建「我喜欢」歌单，后续保持用户已有歌单不变。

修复已登录站点仍提示“需要登录”的问题：登录接口自身的成功响应不再被误判为未登录；口令错误时显示明确的“登录失败”，而非笼统的站点错误。站点会话失效时会提示重新登录。

网易云歌单导入时，若部分曲目因下架、版权限制或字段缺失而无法读取，现在会明确显示“X 首导入失败”，并计入原歌单总数差，不再静默少导。

### 导入本地歌曲（1.8.0）

本地歌单详情页的“歌单管理”菜单新增“导入本地歌曲”：通过系统文件选择器多选手机里的音频文件（支持 mp3、flac、m4a、ogg、wav 等系统可识别的音频），读取标题、歌手与专辑后加入当前歌单。重复选择同一文件自动去重；同一文件可加入多份歌单。

导入的本地歌曲以 `local` 音源保存，播放时直接读取本地文件，不消耗流量、不需要音乐接口；离线可用，不请求在线歌词与封面。本地歌曲可参与歌单内搜索、上移下移、移除、播放顺序等功能；导出与网页版兼容的便携 JSON 时不会携带本机文件地址。

### 导入修复与播放回退（1.8.1）

修复 1.8.0「导入本地歌曲」静默失败：导入流程内部调用了带“操作进行中”守卫的歌单接口，守卫把内层调用直接拦截，歌曲从未写入歌单。现在导入直接写入存储层；已有同名「本地音乐」歌单时自动并入，不再因重名报错。同时导入时持久化文件读取权限，进程重启后歌单里的本地歌曲仍可播放；SAF 文档 URI 读不到 MediaStore 元数据时退回文件名，导入不再因元数据缺失而失败。

在线播放与网页端对齐，修复部分网页可播的歌曲在安卓端失败：

- 音频直链解析后先轻量探测可用性，优先 HTTPS，失败回退上游原始 HTTP 地址；酷我保留上游要求的 HTTP。
- 直链保留 15 分钟内存缓存（与网页一致），拖动进度触发的重复解析不再请求接口，也避免接口被频繁请求后限流。
- 播放失败自动作废直链缓存并重新解析重试一次（等价网页的 nocache 重试）；本地文件与已重试曲目不重试。
- 请求统一携带浏览器 UA（网页端即浏览器 UA，部分 CDN 拒绝陌生客户端 UA），网络配置放行明文 HTTP 以支持仅 HTTP 的音频 CDN，站点与音乐接口仍在设置校验中强制 HTTPS。

### 可选主题与播放诊断（未发版）

在“设置 → 外观 → 主题风格”选择“终末地风格”，点击“保存设置”后启用。工业黄、灰色面板、切角和方形播放器封面支持浅色、深色及跟随系统；首次安装和旧版本升级均保持 Solara 默认风格，随时可以切回。

若同一首歌出现声音突然变大或变小，可在发生后进入“设置 → 播放诊断 → 导出播放诊断”。应用仅在内存中保留本次运行最近 200 条播放与音量事件，不录制音频、不记录歌曲地址或口令，关闭进程后清空。诊断观察并原样转发输出增益，不改变系统音量或音频焦点策略；部分系统自动压低、蓝牙音量与音效不会反映在应用增益中。音量异常仍需结合发生时的记录定位，不能视为已确认修复。

## 构建

需要 JDK 17、Android SDK 35；Gradle Wrapper 固定为 8.9。所有网络仓库使用 Google Maven 和 Maven Central。

```powershell
# 设置仅影响当前 PowerShell 进程
$env:JAVA_HOME = '你的 JDK 17 目录'
$env:ANDROID_HOME = '你的 Android SDK 目录'
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`。Debug 签名用于本地安装；应用商店发布需要自行配置正式签名。

在本次工作站可运行 `./build-local.ps1` 复用已隔离的 JDK、SDK、Gradle 和缓存，不写系统环境变量。脚本退出时恢复原进程环境。

## 结构与验证

- `data`：沿用上游的音乐/歌单契约、接口、设置与加密会话。
- `playback`：MediaSessionService 拥有播放器和队列，页面通过 MediaController 操作。每首曲目在加载时解析签名 URL。
- `download`：WorkManager 管理后台任务，MediaStore 管理公共音乐文件，流式传输避免整首音频进入内存。
- `ui`：Jetpack Compose 原生页面和弹层，没有 WebView、HTML 页面或 JavaScript 界面桥接。
- `ContractTest`：接口参数、歌单兼容、歌词、音频识别、下载完整性、取消和错误响应的集中验证。
- `LocalPlaylistTest` / `LibraryStoreTest`：命名校验、去重、独立排序及移除、序列化；通过 Robolectric 验证 Android SharedPreferences 中新旧数据共存及重新读取。

界面支持竖屏滚动、宽屏双栏、系统返回键、亮暗主题；触控使用原生控件。构建、单测、Lint 与在线接口验证不能替代真机的音频焦点、锁屏、厂商省电策略和文件写入验收，详见开发报告。
